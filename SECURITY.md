# Security

Thank you for helping keep UltimaPress and the sites built with it safe.

## Reporting a vulnerability

Please report security issues privately. Don't open a public issue, comment or post about
them until a fix is available.

**Report it here:** [Report a vulnerability](https://github.com/mrwebtv/ultimapress/security/advisories/new)
(the Security tab of this repository). Only you and the maintainer can see the report.

No GitHub account? Get in touch through [mrweb.tv](https://mrweb.tv) and ask for a private
channel. Don't include the details in your first message.

Please include:

- what the issue is and what an attacker could do with it;
- the steps to reproduce it, or a proof of concept;
- the UltimaPress version or commit you tested.

## What happens next

- You'll get a reply acknowledging your report.
- We'll confirm the issue, work on a fix and agree with you when it can be made public.
- Fixes go out as a new version. Site owners get them by pressing Update.
- With your permission, you'll be credited in the advisory.

## Scope

In scope: the code in this repository, including the admin, the Claude connection, the
Site code update system and the Docker setup.

Out of scope: features a site owner has added to their own copy, the owner's server
and hosting, and third-party services such as Hostinger, GitHub or Claude, which have
their own reporting routes.

## Supported versions

Security fixes are made to the latest version of UltimaPress.
